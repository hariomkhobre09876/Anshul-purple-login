# Hariom Purple Login Demo

A responsive Next.js + TypeScript + Tailwind CSS demo inspired by the supplied purple glassmorphism sign-in card.

## Run locally
1. Install Node.js on a computer.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open `http://localhost:3000`.

## Publish online
1. Upload this project to a GitHub repository.
2. Sign in to Vercel and import that repository.
3. Keep the detected Next.js settings and click Deploy.
4. Vercel will provide a public URL after the deployment succeeds.

## Important
This is a visual demo only. The form does not authenticate users, store passwords, or send credentials to a server. Do not use it to collect real login information.
